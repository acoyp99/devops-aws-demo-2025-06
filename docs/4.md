#### 💡 Discoveries & Learnings
- Bitnami PostgreSQL Helm chart requires correct `storageClass` for local K8s
- Artifactory's `database.url` must use cluster DNS for internal access
- `psql` client via Kubernetes pod is useful for DB connection testing

#### 💾 Code Applied
```bash
# PostgreSQL install
helm install artifactory-postgres bitnami/postgresql --namespace postgresql -f postgres-values.yaml

# Artifactory install
helm upgrade --install artifactory jfrog/artifactory --namespace artifactory -f artifactory-values.yaml
```
```yaml
# Example from postgres-values.yaml
auth:
  username: artifactory
  password: artifactory123
  database: artifactorydb

# Example from artifactory-values.yaml
artifactory:
  database:
    type: postgresql
    url: jdbc:postgresql://artifactory-postgres.postgresql.svc.cluster.local:5432/artifactorydb
    user: artifactory
    password: artifactory123
```
