### Chatbot Deployment App

This [code](../chatbot-deployment/) is part of a chatbot development project cloned from the repository:
 `https://github.com/python-engineer/chatbot-deployment.git`.

 Steps to set up and run the chatbot:
 1. Clone the repository using the command:
    `git clone https://github.com/python-engineer/chatbot-deployment.git`
 2. Navigate to the project directory and start the application by running:
    `python app.py`

 Application Details:
 - The chatbot is served using Flask, a lightweight web framework.
 - Debug mode is enabled for development purposes.
 - The application runs locally on `http://127.0.0.1:5000`.
 - Static assets such as JavaScript, CSS, and images are loaded successfully.
 - A warning is displayed indicating that the server is for development use only and should not be used in production.

 Logs:
 - The server logs HTTP requests for resources such as the main page, static files, and favicon.
 - A 404 error is logged for the missing favicon resource.
 - The application restarts automatically when changes are detected due to the active debugger.

 Note:
 - Press `CTRL+C` to stop the server.
 - For production deployment, use a production-grade WSGI server.
